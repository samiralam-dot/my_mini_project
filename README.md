# # Portfolio Website

This is a personal portfolio website built using HTML and CSS. The project showcases my skills, experience, and contact information in a modern, responsive layout.

## Features

- **Navigation Bar:** Easy access to Home, About, and Contact sections.
- **Hero Section:** Introduction with name, short bio, and social media links.
- **About Section:** Details about my background and frontend development skills.
- **Contact Section:** Simple contact form for visitors to reach out.
- **Responsive Design:** Works well on desktops and mobile devices.
- **Font Awesome Icons:** Social media icons for better visual appeal.

## Technologies Used

- HTML5
- CSS3
- [Font Awesome](https://fontawesome.com/)
